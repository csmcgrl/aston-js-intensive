# Почему, если обратиться к переменным созданным через let, const до их объявления - мы получаем ReferenceError?

Все дело в особенности механизма всплытия переменных, объявленных с помощью этих ключевых слов, а также в такой концепции как *"мертвая зона"*.
В отличие от переменной, объявленной с помощью `var`, переменные, объявленные с `let` и `const`, не инициализируются до момента, когда интерпретатор доходит до строки кода, где они объявлены. До своего объявления такие переменные фактически находится в так называемой "мертвой зоне", то есть даже если они существуют в своей области видимости, мы не можем к ним обратиться до их объявления.
Например:
```
function example() {
    console.log(a); // ReferenceError: Cannot access 'a' before initialization
    let a = 5; // Объявление переменной происходит только здесь
}
```
