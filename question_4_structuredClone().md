# Глобальная функции structuredClone(). Как использовать?
Функция *structuredClone()* в JavaScript используется для создания **глубоких** копий объектов. Это значит, что она копирует не только сам объект, но и все его вложенные структуры, такие как массивы и другие объекты.  
Вот основные моменты работы данной функции:
### 1. Глубокое клонирование:
Если вы измените клонированный объект, оригинал останется прежним. Например, если у вас есть объект с вложенными данными, изменения в клоне не повлияют на оригинал.  
Допустим, у нас есть объект с информацией о человеке:
```
const person = {
    name: "Alice",
    age: 30,
    hobbies: ["reading", "traveling"]
};
```
Создаем его копию с помощью функции structuredClone():
```
const personClone = structuredClone(person);
```
Мы можем изменить personClone, и это не повлияет на оригинальный объект person:
```
personClone.hobbies.push("coding");
console.log(person.hobbies); // ["reading", "traveling"]
```
Оригинальный объект остался без изменений.

### 2. Поддержка разных типов данных:
Функция может копировать разные типы данных, включая даты, массивы и даже сложные структуры, такие как карты и множества (Date, Set, Map, ArrayBuffer, Blob, File, ImageData).
### 3. Работа с циклическими ссылками:
Если мы работаем с объектом, который ссылается на себя, structuredClone() сможет это правильно обработать без ошибок.
## Ограничения:
* Прототипы: Если вы используете structuredClone() с экземпляром класса, вы получите простой объект в качестве возвращаемого значения, поскольку структурированное копирование отбрасывает цепочку прототипов объекта.
* Функции: Если ваш объект содержит функции, они будут тихо отброшены.
* Не клонируемые: Некоторые значения не структурированы для клонирования, в первую очередь это `Error` и `DOM узлы`. Это приведёт к тому, что structuredClone() вызовет исключение.
